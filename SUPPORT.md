# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the
[existing issues](https://github.com/microsoft/Agent365-Samples/issues) before filing
new issues to avoid duplicates. For new issues, file your bug or feature request as a new Issue.

For help and questions about using the Microsoft Agent 365 SDK and these samples, please refer to the
[Microsoft Agent 365 developer documentation](https://learn.microsoft.com/microsoft-agent-365/developer/).

To report a security vulnerability, do not open a public GitHub Issue. Follow the instructions in
[SECURITY.md](SECURITY.md) instead.

## About these samples

The samples in this repository are provided for learning and demonstration purposes. They are not
intended to be used as-is in production, and they are not supported as production code. Review,
adapt, and test any sample code before using it in your own solutions.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is an open-source project,
and Microsoft product support contracts and service-level agreements (SLAs) do not extend to it.
